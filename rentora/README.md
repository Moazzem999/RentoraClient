# Rentora — Smart Rent Management Landing Page

A responsive, Bootstrap 5 landing page based on the supplied Rentora mockup.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser. For best results, use a local static server (for example, VS Code Live Server).

## Included
- Responsive navigation and hero section
- Property/building illustration and dashboard preview
- Feature highlights, pricing plans, testimonials, FAQ accordion, About, CTA and footer
- Bootstrap modal demo placeholder
- Smooth anchor navigation and active-section highlighting

## Technology
HTML5, CSS3, vanilla JavaScript, Bootstrap 5.3 and Bootstrap Icons.

## Notes
This is a front-end marketing website. Login, subscriptions, account creation, tenant/building management, monthly billing, and data persistence require a backend/API and are not implemented in this static UI. Replace the demo placeholder and connect the CTA links to your application routes when those are available.
